# Netplus · Presentación

Presentación del proyecto de Ingeniería Web, construida únicamente con HTML y CSS.

## Contenido

- Requerimientos funcionales y no funcionales.
- Tecnologías y arquitectura propuesta.
- Espacio para el prototipo embebido de Figma.

## Uso

Abre `index.html` directamente en el navegador o sirve la carpeta con cualquier servidor estático.

El prototipo público de Figma ya está integrado en el `iframe` de `index.html`.

El selector de tema permite elegir entre claro, oscuro y automático mediante radios HTML y selectores CSS. El modo automático sigue la preferencia del sistema operativo.
